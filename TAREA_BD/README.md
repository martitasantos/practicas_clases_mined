# Sistema de Gestión de Alojamientos Turísticos

## Descripción

Este proyecto contiene 20 consultas SQL desarrolladas sobre una base de datos de gestión de alojamientos turísticos como parte de una práctica de PostgreSQL.

## Motor de Base de Datos

* PostgreSQL 17
* Herramienta utilizada: pgAdmin 4

## Base de Datos

Nombre de la base de datos:

```sql
tarea-mined
```

## Tablas principales

* owners
* accommodations
* accommodation_types
* accommodation_amenities
* guests
* bookings
* payments
* reviews
* locations

## Consultas desarrolladas

1. Insertar propietario
2. Insertar alojamiento
3. Insertar huésped y reserva
4. Insertar pago
5. Alojamientos activos
6. Huéspedes por país
7. Reservas por fechas
8. Actualizar precio
9. Actualizar estado de reserva
10. Eliminar reseña
11. Reservas y huéspedes (INNER JOIN)
12. Alojamiento completo (INNER JOIN múltiple)
13. Pagos y reservas
14. Alojamientos sin reseñas
15. Alojamientos sin reservas
16. Total de ingresos (SUM)
17. Promedio de calificaciones (AVG)
18. Top alojamientos (COUNT + LIMIT)
19. Alojamientos con más de 3 reservas (HAVING)
20. Alojamiento más caro (Subconsulta)
